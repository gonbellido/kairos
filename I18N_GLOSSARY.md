# I18n Glossary - KAIROS

| English | Español | Context / Notes |
|---------|---------|-----------------|
| Journey | Journey | Standard term in the platform, usually not translated. |
| Phase | Fase | Part of a Journey. |
| Agent | Agente | AI personas. |
| Coach | Coach | The user of the admin/coach panel. |
| Client | Cliente | The person receiving coaching. |
| Imprint | Impronta | Behavioral guidelines for agents. |
| Insight | Insight | Findings from conversations. |
| Pattern | Patrón | Recurring behaviors or themes. |
| Dashboard | Dashboard | Main overview page. |
| Prompt | Prompt | Instructions for LLMs. |
| Vault | Bóveda | Referring to Obsidian storage. |
| Alert | Alerta | System notifications about clients. |
| Score | Puntuación | Numerical evaluation. |
| Clarification | Claridad | Progress metric. |
| Energy | Energía | Progress metric. |
| Resistance | Resistencia | Progress metric. |
| Commitment | Acción | Progress metric (formerly 'accion'). |
