# Guía de Internacionalización (i18n) en KAIROS

La plataforma KAIROS soporta múltiples idiomas (actualmente Español e Inglés) de forma consistente en todas sus capas.

## Arquitectura de i18n

1.  **Detección de Idioma**: El `I18nMiddleware` detecta el idioma del usuario basándose en:
    *   Parámetro de consulta `?lang=es` o `?lang=en`.
    *   Cookie `kairos_lang`.
    *   Cabecera HTTP `Accept-Language`.
    *   Preferencia guardada en el perfil del usuario (Coach) o perfil compartido (Cliente).

2.  **Motor de Traducción (`I18nEngine`)**: Centraliza el acceso a las cadenas de texto ubicadas en `kairos/i18n/{lang}.json`. Utiliza `ContextVar` para que la traducción sea accesible en cualquier parte del hilo de ejecución de la petición sin necesidad de propagar el parámetro `lang`.

3.  **Frontend (Jinja2)**: Se inyecta una función global `t(key)` en todas las plantillas.
    *   Uso: `{{ t('ui.login_title') }}`

4.  **Agentes y Prompts**:
    *   Los prompts por defecto se cargan desde los archivos JSON (`prompts.agente`).
    *   El `PromptStore` gestiona las versiones personalizadas en base de datos filtrando por la columna `lang`.
    *   Todos los prompts generados dinámicamente incluyen una instrucción explícita al final: `IMPORTANT: Respond always in Spanish/English.` para asegurar la consistencia.

## Cómo añadir nuevas traducciones

1.  **Añadir claves al JSON**: Edita `kairos/i18n/es.json` y `kairos/i18n/en.json`. Asegúrate de mantener la misma jerarquía de claves.
2.  **Uso en código Python**:
    ```python
    from kairos.engine.i18n import get_i18n
    text = get_i18n().t("ui.key_name")
    ```
3.  **Uso en plantillas HTML**:
    ```html
    <span>{{ t('ui.key_name') }}</span>
    ```
