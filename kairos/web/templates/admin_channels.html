Cómo configurar Telegram

  1. Crea un bot con @BotFather en Telegram
  2. Copia el token (ej: 123456:ABC-DEF1234ghikl-zyx57W2v1u123ew11)
  3. Pega el token en el campo de configuración del coach
  4. Opcional: añade tu Chat ID para recibir alertas (consíguelo con @userinfobot)
  5. Reinicia el servidor para activar el bot
